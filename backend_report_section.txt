РАЗРАБОТКА СЕРВЕРНОЙ ЧАСТИ ПРИЛОЖЕНИЯ

Серверная часть интернет-магазина настольных игр реализована на платформе ASP.NET Core 8 с использованием языка C#. Для хранения данных применяется PostgreSQL, взаимодействие с базой данных выполняется через ORM Entity Framework Core. Бэкенд предоставляет REST API, через который фронтенд получает каталог игр и выполняет операции с пользователями, корзиной и заказами.

Архитектура приложения разделена на четыре логических слоя:

– Core — доменные модели пользователей, игр, категорий, корзины и заказов;
– Application — бизнес-логика и сценарии работы приложения;
– Infrastructure — подключение к PostgreSQL, работа с EF Core, хеширование паролей и формирование JWT-токенов;
– Presentation — контроллеры REST API и обработка HTTP-запросов.

Такое разделение уменьшает связанность компонентов и позволяет изменять способ хранения данных или пользовательский интерфейс без переработки основной бизнес-логики.

В серверной части реализованы следующие группы API:

– регистрация, авторизация и получение текущего пользователя;
– просмотр и администрирование каталога настольных игр;
– управление категориями;
– добавление, изменение и удаление товаров в корзине;
– создание, просмотр и отмена заказов;
– управление пользователями и их ролями.

Для защиты закрытых эндпоинтов используется JWT-аутентификация. Пароли не сохраняются в открытом виде, а хешируются стандартным механизмом PasswordHasher. Доступ к корзине и заказам предоставляется только авторизованному владельцу. Операции изменения каталога, категорий, ролей пользователей и статусов заказов доступны только администратору. Итоговая стоимость заказа рассчитывается на сервере по данным из базы, что исключает возможность подмены цены со стороны клиента.

Ошибки бизнес-логики централизованно преобразуются в соответствующие HTTP-коды: 400 — некорректные данные, 403 — отсутствие доступа, 404 — объект не найден, 409 — конфликт данных.

Для запуска проекта подготовлена контейнеризация через Docker Compose. Одной командой запускаются три сервиса: PostgreSQL, ASP.NET Core API и React-фронтенд с Nginx. Это обеспечивает одинаковое окружение разработки и упрощает развёртывание приложения:

docker compose up --build
